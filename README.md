## The 8 Core Patterns

Instead of memorizing hundreds of questions, focus on the 8 tools that actually solve them:

1. **Hashmaps / Hashsets:** Remember what you've already seen instantly
2. **Two Pointers:** Walk two pointers from both ends
3. **Sliding Window:** Grow or shrink a moving window
4. **Modified Binary Search:** Cut the search space in half each step
5. **Stack & Prefix Sum:** Track running totals and previous values
6. **Heap / Priority Queue:** Instantly grab the smallest or largest item
7. **BFS / DFS:** Explore trees and graphs step-by-step or go deep
8. **Memoization:** Solve big puzzles by never repeating the same work

## Features

- **Interactive Canvas:** Smooth pan, zoom, and auto-centering across all 8 patterns.
- **37 High-Yield Problems:** Every problem teaches a unique idea with zero clone questions.
- **Smart "Next Up" Button:** Always tells you what to solve next based on your active topic.
- **1-Click Topic Reset:** Clear checked questions for any pattern with one click.
- **Local & Cloud Sync:** Saves progress in your browser automatically, with optional Google sign-in to sync across devices.
- **Direct Practice:** One-click links to open problems directly on LeetCode.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/ShreyanDev5/shreyans-arc.git
cd shreyans-arc

# Install dependencies and start dev server
npm install
npm run dev
```

The app works out of the box using local storage. To enable Google sign-in and cloud sync, copy `.env.example` to `.env` and add your Firebase credentials.
